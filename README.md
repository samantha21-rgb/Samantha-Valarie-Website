# Samantha Valarie — A Universe in Progress

A custom, responsive static website designed as an interactive personal universe rather than a conventional portfolio.

## Deploy to Netlify
1. Extract the ZIP.
2. Open Netlify and choose **Add new site → Deploy manually** (or drag and drop).
3. Drag the extracted folder contents — `index.html`, `style.css`, `script.js`, and this README — into the deploy area.
4. Netlify will publish it and provide a live URL. No build command or publish directory is required.

## Tech
- HTML, CSS, vanilla JavaScript
- Responsive layouts, reduced-motion support, interactive constellation, navigation overlay, and letter modal
- No backend, database, API keys, or build step
- Google Fonts are loaded online; the page falls back to local system fonts if unavailable.

## Personalization
The website is written for Samantha Valarie. The text is intentionally a creative starting point and can be edited directly in `index.html` and the `worlds` object in `script.js`.
